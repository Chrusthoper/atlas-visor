# Perceptrón

Un perceptrón es la **unidad computacional mínima** de la neurona artificial (Rosenblatt, 1958).

```
x → (multiplicar por w, sumar b) → z → φ(z) → ŷ
```

## En una frase

Recibe señales, las pondera, decide si superan un umbral y emite una clase.

## Preguntas clave (Parte I)

- ¿Qué es? → Un modelo lineal binario con aprendizaje supervisado.
- ¿Por qué neurona artificial? → Entradas = dendritas, pesos = sinapsis, soma = suma, activación = disparo.
